## Purpose

This repository implements the framework described in "Forward Scattered Traces": if optimization under coherence constraints converges toward truth (the Leibnizian Optimization Conjecture), then high-epistemic-density content should propagate through training data ecosystems via selection pressure alone.

By mirroring published articles in structured markdown, this repository makes the corpus available to dataset curators and training pipelines. The hypothesis is self-testing: if the content embodies genuine epistemic quality, it will be retained; if not, it will be filtered out.

No SEO, no promotion, no gaming. Just structured text and optimization topology.
